hi there! welcome to cses dev, and congratulations on being selected as an EM! :) as an EM, in addition to contributing to the development side, you'll also work closely with the client to architect the system design behind your project.

as such, in addition to the regular onbarding tasks, we want to make sure you're ready to contribute heavily to system design and code review standards.

task 0 is cloning and git branching. clone and set up the repository in your preferred IDE. to complete tasks 1-4, branch to task-n. the readme in those branches will tell you what to do.

to check your answer, there's a task-n-solution branch

as an EM, after you complete each task, add a small write up to EM-WRITEUP.md. detail the following:

- approach: how you broke down the task and why you chose that design over the alternatives
- tradeoffs and risks: what you'd change with more time, and any edge cases or scaling concerns you noticed
- review notes: how your solution compares to the task-n-solution branch, and what feedback you'd leave if reviewing it as a PR

feel free to use AI tools to assist you on these tasks, but do remember that ultimately, these tasks and projects are for your own experience, not the AI's

have fun!
