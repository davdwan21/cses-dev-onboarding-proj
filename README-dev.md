task 0 is cloning and git branching. clone and set up the repository in your preferred IDE. to complete tasks 1-4, branch to task-n. the readme in those branches will tell you what to do.

to check your answer, there's a task-n-solution branch

feel free to use AI tools to assist you on these tasks, but do remember that ultimately, these tasks and projects are for your own experience, not the AI's

have fun!
